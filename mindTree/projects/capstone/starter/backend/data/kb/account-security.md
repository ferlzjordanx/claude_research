# Account security

## Password resets
Customers reset passwords from the sign-in page. Agents must never
ask for or set a customer's password.

## Changing the delivery address
For security, the delivery address of an order in transit can only
be changed by the account owner in the portal, and only before the
parcel reaches the final depot.

## Suspicious activity
If a customer reports orders they did not place, the agent locks the
account and escalates to the security team immediately.
