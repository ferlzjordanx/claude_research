# Cancelling an Order

## Before the order ships

You can cancel an order from Orders in your account until it ships.
The card authorization is released within 3 business days.

## After the order ships

Once an order has shipped it cannot be cancelled. Wait for delivery
and request a return and refund instead, as described in the refund
policy.

## Changing an address

Address changes are possible only before the order ships. Contact
support quickly; we cannot redirect parcels already with the carrier.
